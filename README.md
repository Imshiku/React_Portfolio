# Shaquib Ahmad Portfolio

A responsive multi-page portfolio built with React, Vite, Tailwind CSS and Framer Motion.

## Routes

- `/` — Home
- `/about` — About + skills
- `/projects` — Projects
- `/contact` — Contact

The app uses lightweight client-side routing without adding a routing dependency. Vercel rewrites are configured so direct navigation to any route works in production.
